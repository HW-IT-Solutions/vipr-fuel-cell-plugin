# Example results

This directory contains a curated, human-readable export of the packaged PEMFC
example. It was generated with
`vipr_fuel_cell/examples/configs/pemfc_operating_state_reconstruction.yaml`.

The export includes SVG figures, CSV and text tables, and standalone plotting
scripts with their required data. VIPR's internal `data.pkl` result file is not
included because it is not needed to inspect or reproduce the exported plots.
